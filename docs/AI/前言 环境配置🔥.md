#### conda 指令

`conda` ：检验conda安装成功
`conda create -n python37 python==3.7.3` : 创建python环境
`conda env list` ：已创建的环境列表 
`conda activate python37`：激活虚拟环境，进入该虚拟环境

一般，项目中有requirements.txt来指定所需环境。在与requirements.txt的同级目录下执行：
`pip install -r requirements.txt` 或者`conda install -r requirements.txt` 安装指定环境

>[!hint]
>pip是从“菜市场”来安装；conda是从“超市”来安装。有些库conda没有，pip中可以找到

### VSCode使用注意🔥
vscode打开一个项目文件夹，
命令面板输入`Python: Select Interpreter` 选择虚拟环境。
然后打开终端运行。
因为终端默认为power shell，而powershell会拦截脚本，所以需先在powershell执行Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned设置本地脚本通过策略。
然后powershell执行`conda init powershell`：告诉 Conda 把它的配置文件写入到 PowerShell 里。
最后重新打开终端运行。如图所示，环境成功切换到了（env4）

### python导入包注意
1、
Python 中，原则上每个 `.py` 文件都必须“独立”导入（import）它自己所需要的所有包。 

重复 import 会不会很慢？不会。Python 底层有一个智能缓存机制。当第一个文件读取到 `import torch` 时，Python 会真正去磁盘加载这个包并放入内存。当第 2 个、第 10 个文件运行到 `import torch` 时，Python 发现这个包已经在内存缓存中了，会直接使用缓存。


2、
`import A` 和 `from A import B` 导入方式的开销没有区别
两种方式，Python 底层的执行过程都是：
1. **查找与编译：** 找到 `A.py` 文件并将其编译为字节码。
2. **完整执行：** 将 `A.py` 从头到尾完整执行一遍。
3. **写入内存：** 将整个模块对象存入全局缓存 `sys.modules['A']` 中。
核心结论： `from A import B` **不会**只读取或加载 `B` 部分的代码，它同样把整个 `A` 模块加载到了内存里。
（`import A`更好，看代码一眼就知道 `A.B()` 来自模块 `A`）


3、
对于需要安装的第三方库，`pip install` 的名字和 `import` 的名字经常不一致！！


### PyTorch 安装

在安装PyTorch时，我们通常使用的是**Anaconda/miniconda+Pytorch**+ IDE 的流程。
<font color=#c51111>需要注意cuda,python的版本！！！！！！</font>
cmd终端中输入 `nvidia-smi` , 查看显卡信息和最高支持的CUDA版本；
GPU的版本：4060，驱动程序版本591.86；CUDA Version: 13.1 。
![image.png](https://raw.githubusercontent.com/Easton119/oss/master/test111/20260809232714.png)

在pytorch官网上，（pytorch 版本 2.13.0）选择cuda12.6，找到安装指令
`pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu126`

创建一个python3.12的新虚拟环境；
``` unfold
# 创建一个名为 python312 的新环境，并指定Python版本为3.12
conda create -n python312 python=3.12 -y

# 激活新创建的环境
conda activate python312
```

在python312环境执行安装指令，然后验证

```python unfold
import torch
print(torch.cuda.is_available())
//这条命令意思是检验是否可以调用cuda，如果我们安装的是CPU版本的话会返回False，能够调用GPU的会返回True。一般这个命令不报错的话就证明安装成功。
```
