前面部分是鱼书笔记。

1.正向传播与反向传播

正向传播：根据输入值来计算出结果 反向传播：倒推计算导数

2.层

“层”就是神经网络中功能的单位，比如“乘法层”，“加法层”，“激活函数层”等等 一个“层”作为一个“类”来实现，类中通常包含了forward方法和backwoard方法 例如“乘法层”的backward方法： backward()将从上游传来的导数（dout）乘以正向传播的翻转值，然后传给下游

def backward(self,dout):
	dx = dout*self.y
	dy = dout*self.x
	return dx,dy

Affine层(仿射层)：做神经网络的加权和运算与加偏置运算

ReLU层(修正线性单元)：f(x)=max⁡(0,x)f(x) = \max(0, x)f(x)=max(0,x)。其导数（梯度）计算极其简单，这有效缓解了深层网络中的梯度消失 (Vanishing Gradient) 问题。 （在现代深层网络中取代了之前的Sigmoid函数 f(x)=σ(x)=11+e−xf(x) = \sigma(x) = \frac{1}{1 + e^{-x}}f(x)=σ(x)=1+e−x1​）

如果一个神经网络只包含 Affine 层（仿射层/线性层），那么无论网络堆叠多少层，其结果依然是输入的线性组合：Y=W2(W1X+B1)+B2=(W2W1)X+(W2B1+B2)Y = W_2(W_1X + B_1) + B_2 = (W_2W_1)X + (W_2B_1 + B_2)Y=W2​(W1​X+B1​)+B2​=(W2​W1​)X+(W2​B1​+B2​) 这本质上还是一层线性运算，无法解决类似“异或问题”或图像识别等复杂的非线性任务。 ReLU的数学干预：通过公式 f(x)=max⁡(0,x)f(x) = \max(0, x)f(x)=max(0,x)，ReLU 将所有负值“截断”为 0，正值保持不变。这个简单的操作打破了线性关系，使网络能够通过组合多个神经元的激活状态，去拟合极其复杂的分段线性函数。

Softmax层： yk=exp⁡(ak)∑i=1nexp⁡(ai)y_k = \frac{\exp(a_k)}{\sum_{i=1}^{n} \exp(a_i)}yk​=∑i=1n​exp(ai​)exp(ak​)​，将原始输出转换为概率分布。

Softmax-with-Loss层：在训练阶段，我们将 Softmax 层与损失函数层（通常是交叉熵损失 Cross Entropy Error）合并考虑。将 Softmax 与 Cross Entropy 结合后，其反向传播的梯度形式极其简洁。 假设预测概率为 yky_kyk​，真实标签为 tkt_ktk​（One-hot 编码），则损失函数 LLL 对输入 aka_kak​ 的导数为： ∂L∂ak=yk−tk\frac{\partial L}{\partial a_k} = y_k - t_k∂ak​∂L​=yk​−tk​ 这个结果代表了“预测值与真实值之间的误差”。误差越大，传递回去的梯度就越大，学习步子就迈得越大。

卷积层Convolutional Layer 提取特征 滤波器在图像上像“滑动窗口”一样移动，卷积操作会生成一张新的图，叫做特征图

注意每一个滤波器的通道数和输入数据的通道数一致都为C，但经过一个滤波器处理后得到一个通道 如果用了 FN 个不同的滤波器，输出就会有 FN 个通道

池化层Pooling Layer 如果说卷积是寻找特征，那么池化就是去粗取精 池化是缩小高、长方向上的空间的运算 池化层有以下特征：

  1. 没有要学习的参数
  2. 通道数不发生变化
  3. 对微小的位置变化具有鲁棒性（健壮）

使用im2col函数可以简单、高效地实现卷积层和池化层。

3.计算关于权重参数的梯度

  • 法1：数值微分。利用导数的定义 f(x+h)−f(x−h)2h\frac{f(x+h) - f(x-h)}{2h}2hf(x+h)−f(x−h)​ 来计算。每计算一个参数的梯度，都需要重新运行一遍神经网络的前向传播。如果有 100 万个参数，就要跑 200 万次网络
  • 法2：误差反向传播法。利用“链式法则”，从输出层开始，把误差通过计算图一层层往回传。一次“反向传播”就能算出所有参数的梯度 经常会比较数值微分的结果和误差反向传播法的结果，以确认误差反向传播法的实现是否正确。这种操作称为“梯度确认”

4.CNN

即卷积神经网络 CNN在此前的全连接层的网络中新增了卷积层和池化层。 使用im2col函数可以简单、高效地实现卷积层和池化层。 通过CNN的可视化，可知随着层次变深，提取的信息愈加高级。 LeNet和AlexNet是CNN的代表性网络。

LeNet： 使用sigmoid函数，而现在的CNN中主要使用ReLU函数。 此外，原始的LeNet中使用子采样（subsampling）缩小中间数据的大小，而现在的CNN中Max池化是主流。 AlexNet： • 激活函数使用ReLU。 • 使用进行局部正规化的LRN（Local Response Normalization）层。 • 使用Dropout(在模型训练的过程中，随机让一部分神经元临时“停止工作”（输出变为 0）。极大地缓解了过拟合问题

5.RNN

即循环神经网络。 建立了网络隐层间的时序关联。每一时刻的隐层状态St不仅取决于输入Xt，还包含了上一时刻状态St-1 RNN对时序数据的建模，使得它天生就是一个记账小能手 这种天赋让RNN在自然语言处理NLP领域实现了巨大的飞跃

6.LSTM

长短期记忆网络 它给神经网络装上了一个“高级记事本”和一套“筛选机制”，让它能够自主决定：什么该死记硬背，什么该抛之脑后。
