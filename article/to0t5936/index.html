Anaconda安装

Anaconda3 2025 完全指南：安装、配置与核心操作手册-腾讯云开发者社区-腾讯云 安装anconda3在D:\programData 通过anconda-prompt执行指令来环境管理

默认安装新的环境时装在C盘中， 这时候要修改 D:\ProgramData\anaconda3 的文件权限，修改其属性为所有用户都可以编辑 然后修改config使得安装位置为 D:\ProgramData\anaconda3\envs。

conda 指令

conda ：检验conda安装成功 conda create -n python37 python==3.7.3 : 创建python环境 conda env list ：已创建的环境列表 conda activate python37：激活虚拟环境，进入该虚拟环境

一般，项目中有requirements.txt来指定所需环境。在与requirements.txt的同级目录下执行： pip install -r requirements.txt 或者conda install -r requirements.txt 安装指定环境

[!hint] pip是从“菜市场”来安装；conda是从“超市”来安装。有些库conda没有，pip中可以找到

Pycharm中使用注意

在设置中，可以找到项目-Python解释器，然后选择“添加解释器”， 然后“选择现有”， 类型：Conda， conda的路径： “D:\ProgramData\anaconda3\envs\env4\python.exe”(不确定选择哪个，优先这种) “D:\ProgramData\anaconda3\python.exe” 这是base环境

或“D:\ProgramData\anaconda3\condabin\conda.bat”

环境：env4(env4放在D:\ProgramData\anaconda3\envs里)

新建项目时，解释器类型选择“自定义环境-选择现有”

pycharm经常出现选择环境无反应的情况，重复操作几次，或者“文件-使缓存失效-失效并重启”

import numpy as np  
print(np.__version__)  # 输出numpy版本，验证环境生效

VSCode使用注意🔥

vscode打开一个项目文件夹， 命令面板输入Python: Select Interpreter 选择虚拟环境。 然后打开终端运行。 因为终端默认为power shell，而powershell会拦截脚本，所以需先在powershell执行Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned设置本地脚本通过策略。 然后powershell执行conda init powershell：告诉 Conda 把它的配置文件写入到 PowerShell 里。 最后重新打开终端运行。如图所示，环境成功切换到了（env4）

或者通过“选择默认配置文件”切换为cmd，更省事。

python导入包注意

1、 Python 中，原则上每个 .py 文件都必须“独立”导入（import）它自己所需要的所有包。

重复 import 会不会很慢？不会。Python 底层有一个智能缓存机制。当第一个文件读取到 import torch 时，Python 会真正去磁盘加载这个包并放入内存。当第 2 个、第 10 个文件运行到 import torch 时，Python 发现这个包已经在内存缓存中了，会直接使用缓存。

2、 import A 和 from A import B 导入方式的开销没有区别 两种方式，Python 底层的执行过程都是：

  1. 查找与编译： 找到 A.py 文件并将其编译为字节码。
  2. 完整执行： 将 A.py 从头到尾完整执行一遍。
  3. 写入内存： 将整个模块对象存入全局缓存 sys.modules['A'] 中。 核心结论： from A import B 不会只读取或加载 B 部分的代码，它同样把整个 A 模块加载到了内存里。 （import A更好，看代码一眼就知道 A.B() 来自模块 A）

3、 对于需要安装的第三方库，pip install 的名字和 import 的名字经常不一致！！

PyTorch 安装

在安装PyTorch时，我们通常使用的是Anaconda/miniconda+Pytorch+ IDE 的流程。

cmd终端中输入 nvidia-smi , 查看显卡信息和最高支持的CUDA版本； GPU的版本：4060，驱动程序版本591.86；CUDA Version: 13.1 。

在pytorch官网上，（pytorch 版本 2.13.0）选择cuda12.6，找到安装指令 pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu126

创建一个python3.12的新虚拟环境；

# 创建一个名为 python312 的新环境，并指定Python版本为3.12
conda create -n python312 python=3.12 -y

# 激活新创建的环境
conda activate python312

在python312环境执行安装指令，然后验证

import torch
print(torch.cuda.is_available())
//这条命令意思是检验是否可以调用cuda，如果我们安装的是CPU版本的话会返回False，能够调用GPU的会返回True。一般这个命令不报错的话就证明安装成功。
